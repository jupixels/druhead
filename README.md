# Drunkhead

A 1930s cartoon-style run & gun saloon brawl, inspired by Cuphead. Play it in your browser:
**https://jupixels.github.io/druhead/**

Shotty and Pint ran up a tab they can't pay at the Last Call Saloon. Its owner, Barnaby "Big Tab" Tapsworth, will forgive the debt if they collect IOUs from every deadbeat on the Tipsy Isles.

## Controls (keyboard)
| | Player 1 (left side) | Player 2 (right side) |
|---|---|---|
| Move / aim | W A S D | Arrow keys |
| Jump / parry | V | K |
| Shoot | C | J |
| Dash | B | L |
| EX / Super | F | I |
| Swap weapon | G | O |
| Lock (aim in place) | Left Shift | Right Shift |

In single player you can use either side (Space also jumps). Esc or P pauses, M mutes. Keys can be rebound under **Controls**. Gamepads work too.

## What's in it
- **6 bosses:** Sir Hops-a-Lot, Madame Merlot, The Agave Brothers, Captain Rumbeard (a flying stage), The Mixologist, and the final boss, Big Tab Tapsworth
- **2 run & gun levels** (Pub Crawl, Vineyard Dash), each with a mini-boss and 5 hidden coins
- **The Bar Fight**, a parry-only challenge that unlocks new Supers
- **6 weapons:** Beer Blaster, Whiskey Scatter, Wine Seeker, Champagne Popper, Tequila Charger, Vodka Boomerang, each with its own EX shot
- **3 Supers** and **5 Trinkets**, sold in Barley's Back Room or unlocked in the Bar Fight
- Parrying, a super meter, Light / Regular / Top Shelf difficulty, grades up to S, 3 save slots, local co-op with revives, an overworld with NPCs and secrets, a storybook intro and ending, and an unlockable black & white mode

## Running locally
It's plain HTML + JavaScript with no build step: `python3 -m http.server` in this folder, then open http://localhost:8000.
